# Create Game Character

Deliver an approved likeness integrated across Football, Kickfall, and Disc
Hockey. Follow the repository's [AGENTS.md](../../../AGENTS.md).

1. Inspect the catalog, affected surfaces, and worktree. Infer low-risk details;
   ask only about identity or integration choices that cannot be established.
2. Keep private reference photos outside the repository. Approve the identity
   anchor with the user before generating the twelve-pose sheet. Existing
   explicit approval remains valid unless the likeness changes.
3. Build and inspect the atlas and portrait. Preserve unrelated atlas hashes;
   validate roster proportions, motion consistency, and full-roster collision
   coverage. Numeric checks do not replace visual judgment.
4. Integrate localized catalog data, loaders, selectors, all game modes, fixtures,
   baked artwork where affected, and cache versions. Keep visual scale separate
   from explicit collision profiles and keep Hockey pushers regulation-sized.
5. Complete the applicable workflow's automated and visual checks; report the
   evidence and resolve defects. Obtain final person/guardian likeness approval
   before deployment, and deploy only within the user's authorized scope.
