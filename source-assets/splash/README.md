# Joel Football splash artwork

- `joel-football-option-a-v2.png` is the selected splash source featuring
  Joel's real-photo-derived cartoon likeness. Its optimized 1280×720 WebP
  derivative ships from `public/assets/splash/`.
- `joel-football-option-a.png` is the superseded fictional-character V1 source
  retained only for provenance.
- `joel-football-option-b.png` is intentionally preserved at full resolution
  for a future alternate splash, event screen, or loading-screen rotation. It
  is not included in the production bundle yet.

The V2 source was generated with OpenAI's built-in image generation using the
approved Joel identity anchor and family-supplied photos as private references.
The repository retains only the resulting cartoon art, not the photos.
