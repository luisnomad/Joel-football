# Joel V1 image-generation prompt set

All images were produced on 2026-07-29 with OpenAI's built-in image
generation. The four private family photographs were attached as identity
references but were not copied into the repository.

## Identity anchor

Create one full-body cartoon game character of the same child shown in the
attached photographs. Preserve his dense dark-brown natural curls with close
faded sides, warm medium olive-tan skin, long oval face with tapered chin,
prominent outward ears, dark almond eyes, straight dark eyebrows, slim nose,
and recognizable wide smile. He must read as the same child, at the same age,
not as a generic boy.

Match the polished, softly shaded 2D cartoon style and child proportions of the
existing Joel Football roster. Dress him in a teal V-neck jersey with cream and
gold trim, coral shorts, teal socks, cream-and-gold football shoes, and a coral
wristband. Use a relaxed three-quarter idle stance facing screen-left. Show the
complete figure from hair to shoe soles with generous empty space. Use one flat
bright magenta removable background. No text, frame, props, cast shadow,
gradient, duplicate figure, crop, or magenta in the character.

## Twelve-pose source sheet

Using the approved Joel identity anchor as the exact character reference,
create one 4-column by 3-row contact sheet containing exactly twelve complete
full-body poses of the same child. Preserve the face, curl silhouette, ears,
skin tone, age, head size, body proportions, outfit construction, palette,
shoe design, line weight, soft shading, light direction, and apparent scale in
every cell.

Pose order, left to right:

1. relaxed idle;
2. run contact A;
3. run passing;
4. run contact B;
5. airborne jump;
6. football kick contact;
7. high kick/chilena source;
8. fast forward dash;
9. dizzy/stunned;
10. kick anticipation;
11. bicycle kick;
12. kick recovery.

Every figure must fit completely inside its conceptual cell, including curls,
hands, and shoe soles, with generous separation and no overlap. Use a single
flat bright magenta removable background across the whole sheet. No grid
lines, captions, numbers, text, props, scenery, cast shadows, extra figures, or
magenta in the character.
