# Kickfall obstacle sources

Lossless chroma and alpha sources remain here for the bumper and masonry gate.
Runtime selection is controlled by [Kickfall themes](../../../docs/KICKFALL_THEMES.md).
Vite copies public assets into the build; lazy loading controls requests, not
which files are packaged.

The oval pocket is superseded by the catch rail. Preserve its source files for
provenance; do not restore it merely because the image still exists.

Optional reading for reproducing these assets:
[original prompts and selected files](../../../docs/archive/source-assets/minigames/kickfall/README.md).
